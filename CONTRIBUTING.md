## AI-generated contributions

sessiond does not accept contributions created with large language models
or other generative AI tools.

This covers anything you submit to the project:

- code, tests and commit messages
- documentation and code comments
- issues, pull request descriptions and review comments

You may still use these tools privately to learn,
understand code or explore a problem, as long as what you
submit is written by you. You are expected to understand
every change you submit and be able to explain it.

Contributions that appear to break this policy will be closed.
